# Meta Piano — Audio Design Specification

## Overview

A full 88-key upright piano with medium sustain and a full, warm character. Four
velocity layers per note provide expressive dynamic range from gentle pianissimo to
strong fortissimo. Suited for melodic content, harmonic accompaniment, interactive
instruments, and any context requiring a complete, natural-sounding piano.

## Sample Mapping

- Every chromatic pitch from A0 (MIDI 21) to C8 (MIDI 108) is sampled — no pitch-shifting required
- Map each sample directly to its corresponding MIDI note number
- Each note has four velocity layers; select the layer based on incoming velocity

## Velocity Layers

| Layer | File suffix | Velocity range (0–127) | Dynamic |
|-------|-------------|------------------------|---------|
| 1 | Vel01 | 1–31 | pp (pianissimo) |
| 2 | Vel02 | 32–63 | mp (mezzo-piano) |
| 3 | Vel03 | 64–95 | mf (mezzo-forte) |
| 4 | Vel04 | 96–127 | ff (fortissimo) |

## Playback Guidance

- **Character**: Full, warm upright piano tone with medium sustain
- **Dynamics**: Use the four velocity layers for natural expression — crossfade between adjacent layers for smoother transitions if the engine supports it
- **Sustain**: Medium natural decay; use a 20–50 ms fade-out on note-off to avoid clicks
- **Polyphony**: Supports full polyphonic playback; no voice-stealing constraints from the samples themselves
- **Round-robin**: Single variation per note/velocity; to reduce machine-gun effect on repeated notes, add subtle pitch randomization (±5 cents) and amplitude jitter (±1.5 dB) per trigger

## Usage Contexts

- Playable virtual instrument in VR/AR/MR environments
- Melodic and harmonic content for interactive experiences
- Music production prototyping
- Cinematic scoring and underscore
